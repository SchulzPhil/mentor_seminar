# Mentor's Seminar — практические задания на Go

10 самостоятельных консольных программ. Преподаватель: Владислав Шевченко.

## Запуск

Нужен Go версии 1.20 или новее. Из каталога `mentor_seminar` выполните:

```sh
go run ./task01
```

Для другой задачи замените `task01` на нужную папку. Вводите значения через пробелы или с новой строки. Десятичный разделитель — точка. При неверном или неполном вводе программа выводит сообщение об ошибке и завершается с кодом 1.

## Задания и примеры

| Папка | Задача | Пример ввода | Ожидаемый результат |
| --- | --- | --- | --- |
| `task01` | Калькулятор: два числа, затем операция | `12 4 /` | Результат: 3 |
| `task02` | Анализ целого числа | `-15` | Отрицательное, нечётное, делится на 3 и на 5 |
| `task03` | Сумма и среднее от 1 до N | `5` | Сумма: 15, среднее: 3 |
| `task04` | Таблица умножения, функция `printTable(n)` | `7` | От `7 * 1 = 7` до `7 * 10 = 70` |
| `task05` | Минимум и максимум N чисел | `4 -5 -2 -9 -3` | Максимум: -2, минимум: -9 |
| `task06` | Подсчёт положительных, отрицательных и нулей | `5 -2 0 3 0 -1` | Положительных: 1, отрицательных: 2, нулей: 2 |
| `task07` | Сумма чётных чисел, делящихся на 3 | `12` | Сумма: 18 |
| `task08` | Проверка простоты, функция `isPrime(n int) bool` | `17` | Простое: true |
| `task09` | Банкомат: баланс, действие, при необходимости сумма | `10000 3 2500` | Баланс: 75.00 руб. |
| `task10` | Статистика N целых чисел | `5 -2 0 3 4 5` | Сумма: 10, среднее: 2, максимум: 5, минимум: -2, чётных: 3, нечётных: 2 |

В задачах 5, 6 и 10 первым вводится количество N. В задачах 3, 5 и 10 требуется N > 0; в задачах 6 и 7 допускается N = 0. Ноль считается чётным, но не положительным и не отрицательным. Числа меньше 2 не являются простыми.

Банкомат выполняет одно выбранное действие: 1 — просмотр, 2 — пополнение, 3 — снятие. Денежные суммы вводятся в целых копейках, чтобы избежать погрешностей дробной арифметики; 10000 означает 100 рублей. Баланс должен быть неотрицательным, сумма операции — положительной. Снять больше баланса нельзя.

В задачах 3, 7 и 10 сумма хранится в `float64`; для очень больших целых чисел (выше 2⁵³) возможна потеря точности. Решения предназначены для учебных объёмов ввода. В задаче 8 проверяются делители до квадратного корня числа.

## Проверка

```sh
go test ./...
go vet ./...
```

`go test` проверяет сборку всех программ; отдельные файлы unit-тестов не добавлены. Примеры в таблице позволяют вручную проверить результаты. Дополнительно проверьте деление на ноль, N = 0, отрицательные числа, снятие сверх баланса и ввод текста вместо числа.
